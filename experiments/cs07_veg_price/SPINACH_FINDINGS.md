## 1. 結論

**「産地（前橋）で真夏日（最高気温 ≥30℃）が平年より多い月の翌月、東京市場のほうれんそう入荷量が減り、卸売価格が上がる」**——この先行関係は、15年の月次データで、季節・トレンド・前月価格・降水を統制した分布ラグ回帰でも安定して残る。

| 指標 | 値 |
|---|---|
| 相関（月次15年, n=186, ラグ1か月） | Spearman ρ = **+0.34**（暖候期6〜10月のみ **+0.43**, r²≈0.18）、循環置換 p<0.001 |
| 回帰係数（交絡統制後, ラグ1か月） | β = **+0.0096**（HAC t = +3.3, p = 0.001）。M1〜M4 で不変 |
| 価格への大きさ | 真夏日 **+10日 → 翌月の卸売価格 +約10%** |
| 入荷量への大きさ | 真夏日 **+10日 → 同月〜翌月の入荷量 −15%**（t = −4.6 / −3.2） |
| 経路 | 供給減（入荷量 −15% ↔ 価格 +10%、需要弾力性 ≈ −0.7 で整合） |

「気象単独で価格水準を当てる」ことはできない（予測 R² の上乗せは +0.003）。連続的な**リスク指標**・価格モデルの説明変数としては有効。
ただし **「◯月は高い/安い」を月次で当てる Yes/No アラートとしては弱い**（トレンド除去後 AUC≈0.55、リフト≈1.0倍 — §4.7）。

### 1.1 数値の読み方（この分析での意味）

| 記号 | 意味 | この分析での値と読み方 |
|---|---|---|
| **ρ**（スピアマンの順位相関） | 2つの量が一緒に動くかを **−1〜+1** で表す。値そのものでなく順位で測るので外れ値に強い。読み方は相関係数 r と同じ | **+0.34**（暖候期 **+0.43**）＝「弱〜中」。プラス＝同じ向き（真夏日が多い月ほど翌月の価格が高い） |
| **r²**（決定係数） | ρ（または r）の2乗。「価格の変動のうち**何割を説明できるか**」 | 約 **11%**（暖候期 **18%**）。残り 8〜9 割は他産地の天候・需要・コスト・市場ノイズ |
| **β**（回帰係数＝式の傾き） | 「Xが1単位増えると Y がβだけ変わる」＝**効果の大きさ（単位つき）**。相関が"連動の強さ"なのに対しβは"動かす量" | **+0.0096**（log価格 / 真夏日1日）→ 真夏日 +1日で翌月の価格 約 +1%、**+10日で約 +10%**。入荷量側は −1%/日、+10日で −15% |
| **p 値 / 95%信頼区間** | その数値が偶然で出る確率／真の値が入る範囲 | **p<0.001**、**CI [+0.20, +0.46]**（0 をまたがない）＝「効果なし」は否定される |
| **adj.R²**（自由度調整済み決定係数） | 回帰**モデル全体**が価格変動の何割を説明したか。変数を増やした見かけの上昇を補正した値 | **0.71**。ただし大半は「季節ダミー＋前月価格」由来で、真夏日数を足したぶんの上乗せは **+0.003** |

**なぜ ρ=0.3〜0.4 で「意味がある」と言えるか**: 物理・工学なら \|r\|>0.9 を期待するが、**市場価格は数十の要因で決まる多因子の量**なので、単一の生の気象変数で 0.3〜0.4 出れば十分「中程度」（社会科学の慣習: 0.1 小 / 0.3 中 / 0.5 大）。単一要因で 0.7〜0.8 は原理的に出ない。重要なのは (1) 偶然でない（p・CI）、(2) 他要因を統制しても係数が残る（β の t=3.3）、(3) 方向と時間構造が生理と一致、の3点。

**一文で**: 連動は弱め（ρ≈0.3〜0.4）だが確実で、効果の大きさは無視できない（真夏日+10日で翌月 価格+10%／入荷量−15%）。ただし価格全体の1〜2割しか説明せず、季節と前月価格を知っていれば予測はほぼ改善しない。→ **「価格を当てる」用途には弱いが、「暑い夏 → 来月ほうれんそうが高い」という早期警戒には使える。**

## 2. 検証した仮説（事前登録）

> **H1**: 前橋の「真夏日数（最高気温 ≥30℃ の日数）」の季節偏差が大きい月ほど、その 1〜2 か月後（週次では 2〜4 週後）の東京のほうれんそう卸売価格（季節調整済み log 残差）が高い。ρ > 0、p < 0.05。

気象4特徴（日照・全天日射・降水・高温日数）× ラグ 0〜8 の探索で最大効果量だった組み合わせを、**単一仮説に絞り**、期間を月次15年に拡張し、多重比較を排し、自己相関に頑健な検定で確かめ直したもの。

- 真夏日数 = 月内の「最高気温 ≥30℃」の日数。**季節偏差** = その月の値 − 同一暦月の平均。
- 価格 = log(円/kg)。**季節調整** = 同一暦月の平均 log 価格を差し引いた残差。
- 産地合成の真夏日数 = Σ_産地 w_i(暦月) × 真夏日数_i。ウェイト w は東京入荷の産地別数量から算出（夏は前橋34%・宇都宮32%・水戸14%・盛岡9%・岐阜7% 等）。

## 4. 結果

### 4.1 相関（月次15年）

`spinach_hotdays.py` → [results/spinach_hotdays.png](results/spinach_hotdays.png) / [.txt](results/spinach_hotdays.txt)

| ラグ | ρ | p（通常 / 循環置換） | 95%CI | r² |
|---|---|---|---|---|
| 0 か月 | +0.149 | 0.041 / 0.056 | [+0.01, +0.29] | 0.022 |
| **1 か月** | **+0.336** | **<0.001 / <0.001** | [+0.20, +0.46] | 0.113 |
| 2 か月 | +0.240 | 0.001 / 0.007 | [+0.10, +0.37] | 0.057 |
| 3 か月 | +0.239 | 0.001 / 0.005 | [+0.10, +0.37] | 0.057 |
| **1 か月（暖候期 6〜10月のみ, n=76）** | **+0.427** | **<0.001 / <0.001** | [+0.22, +0.59] | **0.182** |

- 効果は**ラグ1〜2か月**にあり、同月（ラグ0）は弱い。
- 循環シフト置換検定（暑い夏の連続性など自己相関を保ったまま帰無分布を作成）でも p<0.001 → 見かけの相関ではない。

### 4.2 頑健性

**季節・トレンド交絡**（ラグ1か月・全月）: トレンドは小（真夏日数 +0.14日/年、log価格 +1%/年）。

| 前処理 | ρ | p |
|---|---|---|
| 暦月平均を差し引くのみ | +0.336 | <0.001 |
| ＋ 線形トレンド除去 | +0.311 | <0.001 |
| 前年同月比 YoY（季節・トレンド完全除去） | +0.338 | <0.001 |

→ どの前処理でも ρ ≈ +0.34。ラグ0 < ラグ1 とピークが翌月にある形も、共通トレンド由来を否定。

**しきい値・暑さ指標**（暖候期・ラグ1か月）:

| 指標 | ρ |
|---|---|
| 最高気温 ≥24℃ 日数 | +0.21 |
| 最高気温 ≥25℃ 日数 | +0.29 |
| 最高気温 ≥28℃ 日数 | +0.40 |
| **最高気温 ≥30℃ 日数（真夏日）** | **+0.46** |
| 最高気温 ≥32〜34℃ 日数 | +0.47 |
| 最高気温 ≥35℃ 日数（猛暑日） | +0.37 |
| 月平均 最高気温 / 25〜30℃ 超過度日 | +0.46 / +0.46〜0.47 |

→ 24〜34℃ のどのしきい値でも、どの暑さ指標でも ρ ≈ 0.3〜0.47。30℃ 固有ではなく「暑さ」全般のシグナル。24〜25℃ で立ち上がるのは、ほうれんそうが「25℃以上で生育停止」する生理と一致（§5）。

### 4.3 分布ラグ回帰（交絡統制）

`regress_spinach_hotdays.py` → [results/spinach_hotdays_regression.png](results/spinach_hotdays_regression.png) / [.txt](results/spinach_hotdays_regression.txt)

モデル: `log(価格_t) ~ トレンド + 暦月ダミー + Σ_{k=0..3} β_k·真夏日数偏差_{t−k} (+ 降水偏差, + log価格_{t−1})`
標準誤差 = Newey-West HAC（maxlags=6）。

| モデル | 統制項 | 真夏日数偏差 L1 の β | HAC t | p | ブロック同時検定 p | adj.R² | n |
|---|---|---|---|---|---|---|---|
| M1 | 季節・トレンド | +0.0096 | +3.37 | 0.0008 | 0.0002 | 0.647 | 184 |
| M2 | ＋降水 | +0.0103 | +3.57 | 0.0004 | 0.0002 | 0.647 | 184 |
| M3 | ＋降水＋前月価格(AR1) | +0.0096 | +3.30 | 0.0010 | <0.0001 | 0.708 | 184 |
| M4 | M3 を暖候期6〜11月に限定 | +0.0096 | +3.20 | 0.0014 | 0.0001 | 0.739 | 92 |

- **ラグ1か月の係数が全モデルで β ≈ +0.0096〜0.0103・t > 3・p ≈ 0.001 と安定**。季節・トレンド・前月価格・降水を同時に入れても消えない。効果はラグ1か月にほぼ集中（ラグ0・2・3 は 95%CI が 0 をまたぐ）。
- 大きさ: 真夏日 +1日 → 翌月 +約1%、**+10日 → +約10%**（M3）。
- adj.R² の上乗せは +0.003。前月価格がすでに前月の暑さの結果を含むため、AR モデルへの予測特徴としての追加価値は限界的。

### 4.5 供給（入荷量）チャネル

`log(総入荷量_t) ~ トレンド + 暦月ダミー + Σ_{k} β_k·合成真夏日数偏差_{t−k} + log入荷量_{t−1}`

| ラグ | β（log入荷量 / 真夏日1日） | HAC t | p |
|---|---|---|---|
| **0 か月（同月）** | **−0.0106** | −4.58 | <0.001 |
| **1 か月前** | **−0.0096** | −3.24 | 0.001 |
| 2, 3 か月前 | ≈ 0 | | |

累積 −0.0164（t = −2.24）、ブロック同時検定 p<0.001。真夏日 **+10日 → 入荷量 −15%**。
→ 価格上昇の経路は**供給（入荷量）の減少**。量 −15% ↔ 価格 +10% は需要弾力性 ≈ −0.7 で整合。

### 4.6 出荷カレンダー

`plot_spinach_calendar.py` → [results/spinach_calendar.png](results/spinach_calendar.png)

- **月別平均**: 入荷量は 7〜9月が深い谷（冬の約半分、0.7〜0.9 百万kg/月）。前橋の真夏日数は 7月20日・8月24日がピーク。**真夏日ピーク（7〜8月）の約1か月後に入荷量が底（8〜9月）**。夏どりの作付けカレンダー（播種 6〜8月 → 生育30〜40日 → 出荷 7〜9月）と重なる。
- **暑い夏 vs 涼しい夏**（6〜8月真夏日数の上位/下位5年）: 暑い夏の年は **7〜10月の入荷量が 10〜25% 少ない**。効果が 9〜10月まで尾を引く。
- **年次**: 夏（6〜8月）の真夏日数 × その年の 8〜10月 入荷量 → **Spearman ρ = −0.59（p = 0.021, n = 15）**。2025年（真夏日73日）が最少、2014年（43日）が最多。

### 4.7 早期警戒アラートとして使えるか（結論: 弱い）

`alert_spinach_hotdays.py` → [results/spinach_alert.png](results/spinach_alert.png) / [.txt](results/spinach_alert.txt)

出荷対象月 M（7〜11月）の開始 `lead` 日前で終わる 30日窓の「産地合成 真夏日数」で、**M の価格が"その時代なりに高い"（トレンド除去後の残差で上位1/3）** かを当てられるか、を検証（n=76、リード 10〜60日）。

- **識別力は弱い**: 全期間 AUC ≈ 0.5〜0.65、アラート閾値（窓が暑い側1/3で発報）での**リフト ≈ 1.0倍**（基準 33%、TP=9 / FP=17 / FN=16）。ロジスティック回帰の係数は非有意（p ≈ 0.1〜0.9）。
- **見かけの skill はほぼトレンド由来**: トレンド除去前は AUC 0.70・リフト1.6倍だが、`price_hi ~ 窓真夏日 + year` にすると窓の係数 p=0.24（year も p=0.23）。近年ほど「暑くて高い」＝構造要因を割り引くと、月次の当てる力は残らない。
- **当たる年・外す年**: 2023・2024・2025 の高値は概ね発報できるが、2015・2016・2020 の高値は冷涼な窓で見逃し、2011・2017・2018・2022 は暑い窓でも高値にならず空振り。

**理由**: ④の連続効果（ρ=+0.34, β 有意）は本物だが、(1) 2値化で情報が落ちる、(2) 暖候期のみ n=76 で検出力不足、(3) 「高い/安い」の境目が近年の水準上昇で揺れる。連続の「リスク指標」としては意味があるが、**月ごとの Yes/No アラートとしては現データでは弱い**。

**使えるようにするには**: 週次解像度＋2023年以前を e-Stat 日別調査で補完（n を数倍に）／複数チャネル（他産地・降水・熱帯夜・前月価格）を束ねた確率モデル／出力を「◯月は平年比リスク高」の**連続的な注意喚起**に留める（binary な断定はしない）。

## 5. 園芸学的根拠

ほうれんそうは冷涼性作物で、統計上の効き方が生理と一致する。

| 事項 | 内容 | 出典 |
|---|---|---|
| 生育適温 | 10〜20℃。**25℃以上で生育停止**、暑さに極めて弱い | [タキイ種苗 栽培マニュアル](https://www.takii.co.jp/tsk/manual/hourensou.html) |
| 発芽 | 適温15〜20℃。**25℃超で悪化、30℃以上で発芽率が極端に低下** | [JA新みやぎ ほうれん草栽培マニュアル](https://www.pref.miyagi.jp/documents/45159/horenso-manual.pdf) |
| 発芽（英語文献） | >20℃で阻害開始、35℃で完全抑制。pericarp の熱誘導休眠 | [Effect of Temperature on Seed Germination in Spinach](https://www.researchgate.net/publication/312048125_Effect_of_Temperature_on_Seed_Germination_in_Spinach_Spinacia_oleracea) |
| 抽苔（とう立ち） | 花芽分化は発芽後15〜30日、高温・長日で促進。夏まきは雨よけ＋遮光が必須 | 同上 |

- 相関が立ち上がる 24〜25℃ ＝「生育停止」ライン、最強の 28〜32℃ ＝「発芽激減」帯。
- ラグ1〜2か月 ＝ 播種〜生育期（30〜40日）の高温 → 発芽不良・生育不良・抽苔 → 収穫・出荷減 → 価格上昇、という作物サイクル。

## 6. 解釈と限界

- **直接の高温被害と農家の作付け判断は分離できない**。効果が同月でなくラグ1か月に集中する時間構造は、「発芽・生育の物理的被害」だけでなく「暑い時期の作付けを減らす／遅らせる」判断が生育期間ぶん遅れて出荷減に出る、という説明とも整合する。切り分けには週次の作付面積統計や、出荷を作付け日で追えるデータが要る。**先行指標としてはどちらの経路でも成立する。**
- **暑夏に冷涼産地へ発注を振り替える適応は確認できない**。夏（6〜9月）の冷涼産地（岩手・岐阜・長野・北海道等）シェアは同年の暑さと相関せず（ρ = −0.32, p = 0.24）、2011年 25% → 2025年 7% と構造的に減少しているだけ。適応は産地間の振り替えではなく、産地内（施設・遮光・品種・作付け時期）で起きているとみられる。
- **予測 R² の上乗せは小さい**（前月価格＋暦月ダミーで adj.R² ≈ 0.71、真夏日数を足しても +0.003）。ARモデルへの追加特徴としては限界的。
- **週次（日次データ 2024〜, 2.7年）では非有意**（ラグ3週 ρ = +0.16, p = 0.06）。同符号だが期間が短く検出力不足。サブ月スケールの正確なラグは今のところ決まらない。
- 相関の効果量は最大でも r² ≈ 0.18。「気象単独で価格を当てる」用途には足りない。
