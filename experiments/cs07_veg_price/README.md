# CS-07 スパイク — 産地の日照 → 数週後の葉物卸売価格　【2026-09-02 クローズ / NO-GO・2品目】

**[← experiments](../README.md)** ・ 対象: [ID-25](../../docs/idea_catalog.md) / [CS-07](../../docs/correlation_studies.md)

## 結論（このテーマは終了）
**NO-GO。ID-25「生鮮野菜価格の気象先行指標」は、この最小構成（主産地の週次日照 → 東京卸売価格）では 2品目とも相関が弱く、先行指標として成立しない。**

| 品目 / 産地 | 事前基準（ラグ2-4週 p<0.05, ρ<0） | 最良ラグ | 符号 | 効果量 |
|---|---|---|---|---|
| レタス / 諏訪 | **未達** | ラグ3週 ρ=−0.16 (p=0.064) | 負（＝仮説どおり・日照不足で高値） | r²≈2.5% |
| ほうれんそう / 前橋 | **未達** | ラグ1週 ρ=+0.18 (p=0.036※) | **正（＝仮説と逆・日照過多で高値）** | r²≈3% |

- どちらも **\|ρ\|≈0.2 の"弱"域、r²≈3%**（価格変動の3%しか説明できない）。散布図で目視でも相関はほぼ見えない。
- ほうれんそうのラグ1週は名目 p=0.036 だが、ラグを9個試した多重比較を補正すると非有意（0.036×9≈0.32）。しかも**符号が正**＝「日照が多い週の約1週後に価格がやや高い」。暑さ・抽苔に弱く生育期間が短いほうれんそうの生理と整合するが、**当初仮説（日照不足→高値）とは逆**で、CS-07 の枠組みでは GO にならない。
- 2品目・2.7年・1産地では、弱い効果が埋もれているのか無いのか判別不能。判別には大幅なデータ拡張が必要で費用対効果が見合わないため**打ち切る**。
- ハッカソン向けには、気象単独で価格を当てる方向より [evaluation.md](../../docs/evaluation.md) の別候補（ID-06 熱中症×WBGT, ID-27 大気汚染×気象 等、物理結合が強いもの）を優先する。

> 目的（当初）: 主産地の週次日照時間の平年比が 2〜4週後の東京卸売価格に先行するか。仮説は「日照↓ → 価格↑」＝負の相関。
> 副産物: 気象庁 etrn とベジ探 sch7.do の**完全自動取得**コードは資産として残す。品目は `config.py` の `ACTIVE_CROP` で切替（`lettuce` / `spinach`、追加も容易）。

- `estat`: e-Stat API（`ESTAT_APP_ID` 環境変数＋`STATS_DATA_ID`）。青果物卸売市場調査など。2023年以前の日別はこちら or 農水省「青果物卸売市場調査（日別調査）」。

## 既知の注意点
- **産地シフト**: レタスは夏＝長野、冬＝静岡・茨城など主産地が季節で変わる（CS-07 の「癖」）。
  まず諏訪で通年を見て、弱ければ「夏だけ（5〜10月）諏訪」に絞る、静岡を冬に足す。
- **季節交絡**: 価格は季節性が強い。`analyze_lag_corr.py` は週番号ごとの平均 log 価格を引いて残差で相関を取る。
- 日照の平年比の分母は取得年数ぶんの平均（数年ぶんなので粗い）。年数を伸ばすほど安定。
- 気象庁 etrn は 1 リクエスト＝1か月。`REQUEST_INTERVAL_SEC` で間隔を空けている。

## 考察 — どの診断をどう読み、なぜ NO-GO か（2026-09-02）

### 判定に使った基準（σ・p・効果量）
| 基準 | しきい値 | 意味 |
|---|---|---|
| p 値（Spearman, 両側） | **< 0.05** で有意 | 事前登録した GO 条件。相関が偶然でないと言える最低ライン |
| z = ρ / SE（0 から何σ離れているか） | 有意 = **1.96σ**、"証拠"級 = 3σ | SE(ρ) ≈ 1/√(n−1) |
| ρ の 95%信頼区間 | **0 をまたがない** こと | またぐ＝方向すら確定しない |
| 効果量 \|ρ\| | <0.1 無視 / **0.1–0.3 弱** / 0.3–0.5 中 / >0.5 強 | 実務でモデルを組むなら \|ρ\|≳0.3（r²≳0.1）が欲しい |
| CCF の棒（パネルA） | 破線 **±1.96/√n** を超える | 個々のラグが有意かどうか |

### パネル別の読みと合否
| パネル | 見た点 | 実測 | 基準クリア |
|---|---|---|---|
| **A. CCF** | ラグ+2〜4週が負・負ラグ≒0 の**非対称**（因果の向きと整合） | ラグ3 ρ=−0.159。破線 ±1.96/√136 ≈ **±0.168**。**触れるだけで超えない**。棒は1本も有意でない | ❌ |
| **B. 散布図（通年, ラグ3週）** | 回帰直線の傾き | ρ=−0.159, **p=0.064**, n=136, z=**1.85σ**, 95%CI **[−0.33, +0.01]（0をまたぐ）**, r²≈2.5% | ❌ |
| **C. 5分位バー** | 日照少→高値、日照多→安値へ**単調**か | 非単調（Q2 が最大、Q1 は中程度）。エラーバーは全群 0 をまたぐ | ❌ |
| **D. 夏季のみ（5〜10月, 諏訪が主産地）** | 絞ると ρ が期待方向へ動くか | ρ=−0.21, **p=0.086**, n=66, z=**1.69σ**, 95%CI **[−0.45, +0.03]**, r²≈4%。向きは仮説どおりだが**有意でない** | ❌ |
| **E. ローリング相関（26週窓）** | ずっと負で安定か | −0.45〜+0.25 で**符号が反転**。不安定 | ❌ |
| **F. 週次系列** | 日照の谷の数週後に価格の山、が反復するか | 部分的にそう見える箇所はあるが一貫しない | △ |

**満たした基準：0/6。**

### ほうれんそう（前橋）の所見 — 符号が逆
- **A. CCF**: ラグ0〜1週が正（ラグ1が+95%帯に触れる）、ラグ2〜4はほぼゼロ。レタスのような「前方に偏った負のローブ」ではなく、**短ラグの正の山**。
- **B. 散布図（ラグ1週）**: 右上がり。ρ=+0.178, **p=0.036**, n=138, r²≈3%。多重比較補正で非有意。
- **C. 5分位**: 概ね「日照多→高値」だが非単調（Q4最大、Q5で低下）。
- **D. 夏季のみ**: ρ=+0.15, p=0.234, n=68 → 通年より弱く非有意。
- **E. ローリング相関**: −0.3〜+0.7 で大きく振れる。2025年は正、それ以外は不安定。
- **解釈**: ほうれんそうは高温・強日射で抽苔・葉焼けし、生育期間が短い（30〜40日）ため供給減→価格上昇が**速い**。「日照過多→数日〜1週で高値」は生理的に筋が通る。ただし当初仮説（日照不足→高値、ラグ2〜4週）とは**方向もラグも違う**ため、CS-07 の枠組みでは GO にならず、統計的にも弱い。

### 「向きは支持される」の正体（レタス。傍証であって証拠ではない）
有意性ではなく **符号の一致** を指していた：(1) ラグ2・3・4週がすべて負、(2) CCF が前方（日照が先）に偏る、(3) メカニズム的に正しい季節（夏＝諏訪）で ρ が仮説方向へ動く。
ただしラグを9個試しているので多重比較を考えれば p=0.064 は補正で余裕の非有意。**「もっと丁寧なテストをやる価値がある」以上の意味はない。**

### 打ち切りの理由
2品目とも \|ρ\|≈0.2 の弱域。弱い効果が埋もれているのか無いのかを判別するには (a) 期間を 2018年以前へ延長（e-Stat「青果物卸売市場調査（日別調査）」）、(b) 季節別に産地を切替、(c) 日照だけでなく気温・WBGT・降水も入れる（ほうれんそうは日照より高温が効く可能性）、(d) 価格を YoY 変化率へ——といった作り込みが要る。
仮に全部やっても \|ρ\| が 0.3 に届かなければ「気象単独では弱い」で終わるため、**ハッカソン準備の時間配分としては打ち切りが妥当**と判断。
