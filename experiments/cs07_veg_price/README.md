# CS-07 スパイク — 産地の気象 → 数週後の葉物卸売価格

**[← experiments](../README.md)** ・ 対象: [ID-25](../../docs/idea_catalog.md) / [CS-07](../../docs/correlation_studies.md)
更新: 2026-09-02（① 日照のみ → NO-GO、② 気象特徴を 日照・全天日射・降水・高温日数 に拡張して再検証）

## 結論（現時点）
**「気象単独で葉物価格を"当てる"のは無理（\|ρ\|≲0.3, r²≲0.1）。ただし気象を拡張すると、品目の生理に沿った弱いシグナルが複数チャネルで一致して出る。**
**最有力は「ほうれんそう × 真夏日数（≥30℃）が3週先行」＝ ρ=+0.32, p=0.008, r²≈0.10。** 価格予測モデルの"説明変数の一つ"としてなら意味がありそうで、次段階（期間延長・多重比較に強い検証）に進む価値はある。**

| 品目 / 産地 | 当初基準（日照 ラグ2-4週 p<0.05, ρ<0） | 気象拡張で見えた最強セル | 効果量 | 生理的解釈 |
|---|---|---|---|---|
| **レタス / 長野** | ぎりぎり達（日照 lag3-4 ρ=−0.19, p=0.024/0.031） | 日照↓・日射↓ → 3週後に高値、降水↑ → 4週後に高値、暑さ → 即高値 | \|ρ\|≈0.16〜0.28, r²≈0.03〜0.08 | 涼しい気候の作物。曇天・多雨・高温で生育不良／病害 → 供給減 |
| **ほうれんそう / 前橋** | 未達（符号が逆） | **真夏日数 → 3週後に高値（ρ=+0.32, p=0.008, r²≈0.10）**、日射↑・日照↑ → 1週後に軽く高値 | 真夏日数 r²≈0.10、他は r²≈0.03〜0.05 | 高温で抽苔・葉焼け、生育30〜40日で反応が速い |

### 慎重に見るべき点
- **多重比較**: 5特徴 × 9ラグ = 45セル を見ている。厳密な Bonferroni では p=0.008 も 0.008×45≈0.36 で非有意。厳密には「まだ有意ではない」。
- **研究者の自由度**: レタスの産地を 諏訪→長野 に変えた（長野は全天日射量の観測がある官署だから）。これ自体が結果を動かしうる操作。
- **期間**: 2024-01〜2026-08 の 140週のみ（ベジ探 日別が2024年〜）。
- 効果量は最大でも r²≈0.10。「価格の1割を気象で説明」できるかどうか。

### だが以前より前進した点
- 日照だけの時（諏訪, ρ=−0.16 p=0.064）より、**複数の関連特徴（日照・日射・降水・高温）が同じ生理方向を指す**＝偶然の単発相関ではない可能性が上がった。
- **ほうれんそう × 真夏日数** は 45セル中で唯一 r²≥0.1。ラグ3週＝ほうれんそうの生育期間（30〜40日）とも整合。物理的に最も筋が通る。

> 副産物: 気象庁 etrn（p1+a3 の複数要素）＋ベジ探 sch7.do の**完全自動取得**コード。品目は `config.py` の `ACTIVE_CROP` で切替。

## ② 気象特徴 × ラグの結果（2026-09-02）
`analyze_lag_corr.py`。各セル = 週次の「week-of-year 標準化偏差」と、季節調整 log 価格残差（tラグ週後）の Spearman ρ。`*` は p<0.05（多重比較 未補正）。

### レタス / 長野（140週）
![レタス 特徴×ラグ ヒートマップ](results/lag_corr_lettuce.png)

- **日照時間**: lag2〜4 が負（lag3 −0.19*, lag4 −0.19*）。当初仮説「日照不足→数週後に高値」と一致。
- **全天日射量**: lag2〜4 が負（lag3 −0.16）。日照と同方向で整合。
- **降水量**: lag2〜5 が正（lag4 +0.17*）。多雨→数週後に高値（病害・生育不良）。
- **高温日数（≥25/30℃）**: lag0 が正（夏日数 +0.28*, 真夏日数 +0.24）。暑い週は"その週"の価格が高い（レタスは高温に弱い）。
- 4チャネルとも「気象ストレス→供給減→高値」で符号が生理的に一貫。ただし \|ρ\|≤0.28。

### ほうれんそう / 前橋（140週）
![ほうれんそう 特徴×ラグ ヒートマップ](results/lag_corr_spinach.png)

- **真夏日数（≥30℃）**: **lag3 で ρ=+0.32*（p=0.008, r²≈0.10, n=68）**。本スパイクで最大の効果量。ラグ3週＝生育期間と符合。
- **全天日射量**: lag1 +0.23*（p=0.007）。**日照**: lag1 +0.18*。短ラグの正＝日射・日照が多い週の約1週後に高値。
- **降水量**: lag1 −0.15（p=0.09）。雨で暑さが和らぐ効果か（弱い）。
- レタスと符号が逆（日照・日射・高温いずれも "多い→高値"）＝ほうれんそうは暑さ・強光ストレスに弱い、で一貫。

## 判定基準（σ・p・効果量）
| 基準 | しきい値 | 意味 |
|---|---|---|
| p 値（Spearman, 両側） | < 0.05 で名目有意。ただし 45セル見ているので **×45 で補正**して評価 | 相関が偶然でないと言える最低ライン |
| z = ρ / SE | 有意 1.96σ / "証拠"級 3σ（SE ≈ 1/√(n−1)） | 0 から何σ離れているか |
| 効果量 \|ρ\| | <0.1 無視 / 0.1–0.3 弱 / 0.3–0.5 中 / >0.5 強 | 実務なら \|ρ\|≳0.3（r²≳0.1）が欲しい |
| 事前 GO 条件 | 日照 ラグ2-4週で p<0.05 かつ ρ<0 | 当初登録した唯一の一次仮説 |

## 次にやること（弱シグナルを詰める）
1. **期間を2018年以前へ延長**: ベジ探日別は2024〜。2023年以前の日別は e-Stat「青果物卸売市場調査（日別調査）」/ 農水省から。n を3〜4倍にして多重比較に耐えるか見る。
2. **仮説を1本に絞って事前登録**: 「ほうれんそう × 真夏日数、ラグ2〜4週、ρ>0」だけを検証（多重比較の問題を消す）。
3. **交絡の統制**: 産地の他要因（他産地の作柄、需要期）を入れた分布ラグ回帰へ（`docs/ml_models.md`）。
4. 産地の作り込み: 夏＝高冷地／冬＝関東平野で産地・地点を切替。
5. 品目拡張: こまつな・キャベツ等。`config.CROPS` に追加するだけ。
