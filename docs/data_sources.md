# データソース棚卸し

**[← README（目次）](../README.md)** ・ 関連: [idea_catalog](idea_catalog.md) ・ [correlation_studies](correlation_studies.md) ・ [ml_models](ml_models.md) ・ [existing_assets](existing_assets.md)

ハッカソン（短時間）で使えるかどうかを軸に整理。列: 入手性 / ライセンス / 粒度 / 遅延・更新。

> **絶対ルール（[CLAUDE.md](../CLAUDE.md)）**: 気象データは**気象庁HPから取得**する。Open-Meteo / ERA5 等の再解析・第三者APIは使わない。
> 相手側は**誰でも同じ手順でアクセスできる公開データのみ**。個人データ・非公開データ（`okiden*` の自宅電力、GPSログ、ウェアラブル、本人カレンダー等）は使わない。

## 気象（すべて気象庁）

| ソース | 内容 | 入手性 | ライセンス | 粒度 | 遅延/更新 |
|---|---|---|---|---|---|
| **気象庁 過去の気象データ・ダウンロード** <https://www.data.jma.go.jp/risk/obsdl/index.php> | 気温・降水・日照・全天日射(約48地点)・風・湿度・気圧・積雪の**過去観測CSV** | ◎ 誰でもDL・無料 | 出典明示（「気象庁ホームページ」） | 地点・10分/1時間/日/月 | 確定値は数日後。**1回のDLに容量上限→期間・項目を分割** |
| 気象庁 過去の気象データ検索 <https://www.data.jma.go.jp/obd/stats/etrn/> | 上記の表形式閲覧版 | ○ 手動 or スクレイプ | 同上 | 地点・10分〜日 | 同上 |
| 気象庁 bosai JSON（`www.jma.go.jp/bosai/...`） | 予報・警報・注意報・台風・潮位・アメダス実況・ナウキャスト | ◎ 認証不要JSON | 同上 | 地域〜1km | 数分〜1時間 |
| 気象庁 天気図・衛星画像 | 地上/高層天気図、ひまわり | ◎ 画像 | 同上 | 画像 | 3〜6時間/10分 |
| 気象庁 平年値・気候データ | 平年値、猛暑日日数等の統計 | ○ CSV | 同上 | 地点・旬/月/年 | 年次 |
| 気象庁 潮位表・潮位観測 | 天文潮位、潮位観測 | ○ CSV/JSON | 同上 | 地点・1時間/毎分 | 観測は短期のみ（`tide_viewer` 参照） |

> 数値予報GPV（GSM/MSM/LFM）は**GRIBで大容量のため本プロジェクトでは扱わない**。予測が要る場合は bosai の予報JSON/テキストで代替。
> Open-Meteo / ERA5 / NASA POWER / GPM は**方針上、不使用**（過去メモから削除）。

## 相手側データ（分野別）

**公開データのみ。個人データ（ウェアラブル実データ、本人のカレンダー/GPSログ等）は学習・相関には使わない**（デモ画面での本人入力は可）。

| 分野 | ソース | 入手性 | 備考 |
|---|---|---|---|
| 電力需要 | 電力会社「でんき予報／過去の電力使用実績」CSV、一般送配電「エリア需給実績」、OCCTO | ○ 公開DL | 沖縄電力2018年〜／東京電力2016年〜。**`okiden*` の個人データは不可** |
| 電力価格 | JEPX 取引結果CSV | ○ 無料DL | スポット30分値 |
| 太陽光/風力実績 | 一般送配電のエリア需給実績（電源別＝再エネ出力込み） | ○ 公開CSV | 1時間値 |
| 熱中症搬送 | 消防庁「熱中症による救急搬送状況」 | ○ 週報・都道府県別 | 夏季のみ |
| 感染症・媒介生物 | 感染症発生動向調査（IDWR/NIID）、東京都感染症情報センター（CSVDL）、厚労省「定点当たり報告数の推移」 | ○ 週報 | 多年分DL可 |
| 花粉 | 環境省「はなこさん」 | △ 配信期のみ・過去分は別途 | 通年の公開履歴は限定的 |
| 大気汚染 | 「そらまめくん」大気汚染物質広域監視 | ○ 時間値 | ダウンロード機能あり |
| 農業気象 | 農研機構 メッシュ農業気象データ | ○ 要利用申請・APIあり | 誰でも申請可。`nouken` は取得コードの参考 |
| 青果価格 | 農水省 青果物卸売市場調査、e-Stat | ○ 日次/月次 | |
| 商業・消費 | 経産省 商業動態統計（e-Stat） | ○ 月次 | POS詳細は有料のため使わない |
| 交通（運行） | 公共交通オープンデータ（ODPT） | ○ 要登録・無料 | 過去アーカイブは限定的 |
| 道路 | 高速道路会社の通行止め情報、道路交通センサス | △/○ | |
| 地理・災害 | 国土数値情報、重ねるハザードマップ（GeoJSON/タイル）、基盤地図（標高） | ○ | |
| SNS | Bluesky/Mastodon API（無料） | ○ | 災害・体調投稿の抽出。再現性に注意（誰でも同条件で取り直せるか要検討） |

## 生成AI / モデル

| 用途 | 選択肢 | 備考 |
|---|---|---|
| LLM（クラウド） | Claude（Sonnet/Haiku）API | `claude-api` スキル参照。既存digest系で実績 |
| LLM（ローカル） | Ollama（`local_agent` `agent_orchestrator` 環境） | オフライン・コスト0。品質は要検証 |
| VLM | Claude（画像対応） | 天気図・衛星の読み取り（ID-32） |
| 埋め込み/RAG | `RAG_met` の資産 | 気象文書・農薬ラベル等 |
| 時系列ML | LightGBM/XGBoost、statsmodels、sktime、PyTorch(LSTM/ConvLSTM) | まずGBDTで当たりを取る |
| 画像外挿 | オプティカルフロー(OpenCV)、ConvLSTM | ID-21 |
